# EcomPilot V1.6 真实使用验证版

EcomPilot 是一个 Windows 本地优先的电商选品与运营工作台。正式数据以本机 SQLite、`uploads/`、`exports/`、`backups/`、`logs/` 和应用内 `trash/` 为准；Vercel 仅用于只读预览。

## 当前版本定位

- 当前阶段：`V1.6 真实使用验证版`
- 当前目标：先把主流程、版本边界和文档基线摆正，不直接落地大功能
- 当前主方向：从“多个工具页 + 手动填表”调整为“图片驱动的商品与竞品草稿工作台”
- 当前主入口方向：`灵感箱` 作为后续主入口，定位为 `AI 灵感收件箱`
- 当前入口表达：新用户默认先看 `灵感箱`；`截图识别` 是补充识别入口；`/link-imports` 只保留旧路由和辅助来源记录定位
- 当前评分分层：
  - `草稿初筛分` 回答“这条线索值不值得继续看”
  - `正式商品评分` 回答“这个商品值不值得小批量测试”
- 当前商品详情方向：围绕“是否值得小批量测试”重表达
- 当前链接导入方向：降级为 `辅助来源记录`

## V1.6 范围冻结

V1.6 是真实使用验证版，不是大功能落地版。

V1.6 必须坚持：

1. 不做大功能重构或大范围新系统。
2. 不落地竞品截图收件箱。
3. 不落地商品确认后的自动内容工作流。
4. 不把 API 生图作为 V1.6 工作目标。
5. 不新增平台爬虫、自动采集、自动打开平台页面、浏览器自动化、Cookie、登录态、自动上架、自动私信、自动评论。
6. 不自动创建正式商品。
7. 不自动写入正式竞品。
8. 不自动污染正式评分。
9. 不让 Vercel 承担真实写入验收。

说明：

- V1.5 已经存在“可选、手动、单次触发”的 API 生图能力，但它不属于 V1.6 本轮主线，不在本轮扩展。
- V1.6 只允许做文档同步、信息架构重排、主流程表达调整和轻量体验梳理。

## 本地运行

请在 PowerShell 中执行：

```powershell
cd <项目目录>
npm install
Copy-Item .env.example .env
npx prisma migrate dev
npm run prisma:seed
npm run dev
```

然后访问 [http://localhost:3000](http://localhost:3000)。

也可以双击 `start.bat` 启动本地环境。

## 本地目录

- `uploads/`：商品主图、竞品截图、素材图、Prompt 回传图、灵感图、截图识别图及其缩略图
- `exports/`：Excel 导出文件
- `backups/`：手动备份目录
- `logs/`：脱敏应用日志
- `trash/`：EcomPilot 应用内回收站

这些目录是本地运行数据，不应提交到 Git。前端、导出、诊断、通知和日志只展示相对路径或脱敏摘要，不展示完整 Windows 绝对路径、数据库真实路径、API Key、`.env` 值、完整 Prompt 或完整堆栈。

## Vercel 只读边界

Vercel 只用于页面预览和可访问性检查，不用于正式写入验收。

预览环境必须满足：

1. 可以打开主要页面并展示只读数据或安全降级内容。
2. 不写 SQLite、`uploads/`、`exports/`、`backups/`、`logs/`、`trash/`。
3. 不执行真实文件扫描、移动、删除。
4. 不执行高成本 AI。
5. 不执行 API 生图。
6. 不执行 Electron POC。
7. 所有写操作统一提示：`预览环境只读，请在 Windows 本地验收。`

## 当前主流程方向

后续主流程调整为：

`图片 / 截图 -> 灵感箱扫描 -> AI 商品草稿 -> 草稿初筛分 -> 用户保留 / 放弃 / 转商品 -> 正式商品 -> 正式评估 -> 条件式内容生产`

核心原则：

1. 用户负责收集图片和确认关键结果。
2. 系统负责扫描、识别、组织草稿和数据。
3. AI 负责辅助提取信息、生成草稿、给建议和做初筛。
4. 正式商品、正式竞品、正式评分、文件删除等关键动作必须用户确认。

## 既有能力说明

V1.5 已完成并保留的既有能力包括：

- 灵感文件夹扫描与 AI 草稿
- 截图识别与结构化草稿
- 链接导入草稿（旧路由保留，作为辅助来源记录）
- 竞品智能分析快照
- 图片去重提示
- 可选手动 API 生图
- 站内助手
- 文件清理与应用内回收站

但在 V1.6 中，这些能力的主次关系发生变化：

- `灵感箱` 上升为主入口方向
- `截图识别` 是补充识别入口
- `链接导入` 降级为辅助来源记录
- `API 生图` 不是 V1.6 当前工作目标

## 文件清理边界

入口：`/maintenance/files`

- 这是既有的 V1-Plus 文件清理与回收站系统
- V1.6 不新增第二套清理系统
- 永久删除仍只允许删除已进入应用内 `trash/` 的文件
- 删除商品默认不是自动删除文件
- 未来空竞品目录也不应被当作普通垃圾自动清理
