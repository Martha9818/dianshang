# Local Assistant Module

## Responsibility

`src/lib/modules/local-assistant/` owns V1.5 Thread 08 lightweight in-app assistant behavior for `/assistant`.

- It converts natural-language questions into safe local search or filter suggestions.
- It builds notification, todo, AI-failure, backup, and cleanup-record summaries from local data.
- It returns only read-only actions: `view`, `search`, `filter`, and `navigate`.

## Safety Rules

- This module is not a real multi-agent system.
- It never executes delete, archive, batch update, mark-read, generate-image, cleanup, move-to-trash, permanent-delete, or status-update actions.
- Final links must be generated by the local rule allowlist; AI output is advisory intermediate data only.
- File cleanup remains owned by V1-Plus Thread 06. This module may only remind, summarize, and link to `/maintenance/files`.
- Vercel preview is read-only and must not call high-cost AI or write SQLite, uploads, exports, backups, logs, or trash.

## Reuse

- Query normalization reuses `src/lib/services/query-service.ts`.
- Todo summaries reuse `src/lib/services/dashboardTodoService.ts`.
- Notification reads reuse `src/lib/services/notificationService.ts`.
- AI intent parsing reuses the existing AI provider, AIJob, and AIRequestLog base.
